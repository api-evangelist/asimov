# Asimov

> Asimov is a synthetic biology company building an integrated platform for the intelligent design of living systems. Its Edge Systems (CHO, LV, AAV, and RNA) combine engineered mammalian host cells, a library of more than 1,000 validated genetic parts, and cloud-based genetic design software so biopharma partners can design and manufacture advanced therapeutics. No public developer API is currently published.

## Products
- [CHO Edge System](https://www.asimov.com/): Host-cell + genetic-design system for biologics production.
- [LV Edge System](https://www.asimov.com/): Lentiviral system for cell therapies.
- [AAV Edge System](https://www.asimov.com/): Adeno-associated virus system for gene therapies.
- [RNA Edge System](https://www.asimov.com/): System for RNA therapeutics candidate development.
